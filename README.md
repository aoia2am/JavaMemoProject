
# JavaMemoProject

頭の中にある考えや「やること」を自由に書き出し、
メモを整理・細分化することで、
「今、自分が何をすればいいか」を分かりやすくするJava CLIアプリです。

## コンセプト

整理できていない考えを、
最初からきれいに分類するのは負担になります。

そのためこのアプリでは、
まず「白紙に書き出す」ことから始めます。

思いついたことをそのまま保存し、
あとからプロジェクトに分けたり、
大きなメモを細かくしたりしながら整理していきます。

整理を先に求めるのではなく、
まず受け止めてから整えることで、
「今やること」が自然に見えてくる仕組みを目指しました。

## 主な機能

- 自由入力した文章をメモとして保存
- 「。」「！」「？」や改行によるメモの分割
- 未整理メモの管理
- プロジェクトの作成・編集・削除
- プロジェクトの並び替え
- メモの作成・編集・削除
- メモの階層化
- メモの並び替え
- 「今やること」の自動表示
- 子メモ完了時の親メモ自動完了
- プロジェクト完了時のアーカイブ表示
- テキストファイルによるデータ保存

## 実行方法

1. Eclipseでプロジェクトを開きます。
2. Java 17が設定されていることを確認します。
3. `Main.java` を右クリックします。
4. `Run As > Java Application` を選択します。

## データ保存

メモやプロジェクトのデータは、
実行時に作成される `data` フォルダ内のテキストファイルに保存されます。

```text
data/
├── projects.txt
└── memos.txt
```

`data` フォルダはGitの管理対象外です。

アプリを終了して再起動しても、
保存したメモ、プロジェクト、並び順、完了状態を引き継ぐことができます。

## クラス構成

### Main

アプリの起動とHOME画面のメニュー制御を担当します。

### Project

プロジェクトのデータを保持します。

### Memo

メモのデータを保持します。

### ProjectProcess

プロジェクトの作成・編集・削除・並び替えなどを担当します。

### MemoProcess

メモの作成・整理・編集・削除・細分化・並び替え・完了処理などを担当します。

### FileManager

プロジェクトとメモの保存・読み込みを担当します。

### ConsoleUtil

CLI画面の共通表示を担当します。

## 工夫した点

* 最初から整理を求めず、まず自由に書き出せるようにした
* メモを親子構造にし、大きなやることを段階的に細かくできるようにした
* メモの階層を `1-(1)` のように表示した
* メモ削除後に順番が自動で詰まるようにした
* メモとプロジェクトを並び替えられるようにした
* 子メモがすべて完了すると親メモも自動で完了するようにした
* 「今やること」を1つだけ表示するようにした
* CLI上に現在地を表示し、操作中の画面を分かりやすくした
* テキストファイルへ保存し、再起動後も状態を保持できるようにした

## Git運用

* `main`：動作確認済みの安定版
* `develop`：修正や改善を行う作業用ブランチ

修正内容は `develop` で作業し、
確認後にPull Requestを通して `main` へ反映します。
